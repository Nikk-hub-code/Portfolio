# 💻 Kaushal Terminal Portfolio

A futuristic **terminal-style developer portfolio** built using **HTML, CSS, and JavaScript** featuring an interactive AI-inspired robot assistant, voice responses, command-based navigation, and cyberpunk aesthetics.

Designed to simulate a real developer terminal experience while showcasing projects, technical skills, and personality in an engaging way.

---

## 🚀 Live Demo

👉 https://nikkode.vercel.app/

## ✨ Features

### 🖥️ Interactive Terminal UI
- Command-driven portfolio navigation
- Real terminal-inspired experience
- Smooth typing interactions
- Command history support

### 🤖 AI Robot Assistant
- Animated floating robot
- Eye tracking based on cursor movement
- Thinking, success, and error states
- Futuristic AI-inspired design

### 🔊 Voice Interaction
- Text-to-Speech responses
- Dynamic voice feedback
- Uses the Web Speech API

### ⚡ Terminal Functionalities
- Command execution system
- Arrow Up / Arrow Down history navigation
- Clear terminal functionality
- Animated typing intro

### 🎨 Cyberpunk Styling
- Neon glow effects
- CRT scanline overlay
- Hacker-inspired aesthetic
- Smooth animations & transitions

### 📱 Responsive Design
- Desktop optimized
- Adaptive layout behavior
- Modern flexbox structure

# 🧾 Available Commands

| Command | Description |
|----------|-------------|
| `help` | Show all available commands |
| `whoami` | Introduction about me |
| `skills` | Technical skills and technologies |
| `projects` | Featured projects |
| `education` | Educational background |
| `experience` | Learning journey and development |
| `achievements` | Certifications and achievements |
| `resume` | Resume overview |
| `contact` | Contact information |
| `clear` | Clear the terminal screen |
